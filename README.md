# Date Question Website ❤️

A tiny GitHub Pages website for asking someone out.

## Customize
Open `index.html` and replace `[HER NAME]` with her name. You can also edit the text inside the page.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `date-question`.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. After GitHub publishes it, your site will be available at:
   `https://YOUR-USERNAME.github.io/date-question/`
